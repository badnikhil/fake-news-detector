# End-to-end evaluation — Live Claims Set (eval split)

Generated by `make eval-e2e` (`python -m src.eval.eval_e2e`). Items: the **65 `eval` items** of `data/live_claims/live_claims.csv` (the 30 `dev` items were used only for fusion tuning and are excluded). Each claim goes through `src.api.pipeline.analyze` (the code behind `POST /analyze`) as a headline with `published = claim_date` (else `factcheck_date`). Gold = the fact-checker's rating mapped to 5 classes (`data/live_claims/README.md`). Fusion thresholds: tau 0.6, min_evidence 2, N_months 6 (`fusion.yaml`). Content classifier used: distilbert-welfake-v1. Online = offline FAISS index + ddgs (DuckDuckGo) + Wikipedia; Google Fact Check was **not** used (no API key). Predictions: `train_logs/e2e_eval_{offline,online}_full.jsonl`.
