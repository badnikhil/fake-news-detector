## AI-assisted second pass (NOT a human annotator)

Source: `data/live_claims/second_pass_ai.csv`. Claude sub-agents re-opened each fact-check URL, were given only id / claim / URL (never `label` or `original_rating`), read the verdict on the page and mapped it with the README rules. **This is not an independent human annotator and does not satisfy the ESE DoD "every item double-labelled"**; it mostly checks that the label column still matches the live pages and that the mapping is applied consistently.

Caveats: κ is expected to be high because both passes map the same published rating with the same rules; the only room for disagreement is unrated articles and the UNVERIFIABLE-vs-FAKE judgement. Snopes refuses the web-fetch tool (HTTP 402), so its pages were downloaded with curl and the rating read from the page's `reviewRating` (the same field the first pass used). Some `evidence_quote`s are the page's meta description or a fetch-tool summary rather than a verbatim body sentence; quotes over 20 words are cut with "…". Pass run 2026-11-12.
