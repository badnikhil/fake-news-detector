## Fusion-threshold tuning (dev slice of the Live Claims Set)

Generated by `python -m src.eval.eval_e2e tune` (`make tune-fusion`). Data: the **30 `dev` items** only (`split == dev`; the 65 `eval` items are never used here). Each dev claim was run once through `/analyze` logic in **online** mode (offline index + ddgs + Wikipedia; no Google Fact Check key; evidence cached in `data/cache/evidence.sqlite`), log `train_logs/e2e_dev_online_full.jsonl`. Retrieval and NLI stance are threshold-independent, so every grid point re-runs only the temporal check (`N_months`) and fusion R0–R9 (`tau`, `min_evidence`) on the saved evidence; at the defaults this reproduces the pipeline's verdicts exactly (asserted). Objective: 5-class macro-F1; ties broken by accuracy, then by closeness to the MSE2 defaults.

Grid: tau [0.3, 0.45, 0.6, 0.8, 1.0] × min_evidence [1, 2, 3] × N_months [3, 6, 12] = 45 configs. Rules fired on dev at the defaults: {'R1': 10, 'R3': 7, 'R9': 6, 'R8': 6, 'R7': 1}. Content classifier (R8 tie-break, ±0.10 confidence): distilbert-welfake-v1.

**Default (MSE2)** tau 0.6, min_evidence 2, N_months 6: macro-F1 **0.1542**, accuracy 0.2000.  
**Best** tau 0.6, min_evidence 1, N_months 6: macro-F1 **0.1576**, accuracy 0.2000 (6 configs share this macro-F1).

Caveat: 30 items (3 UNVERIFIABLE, 6 MISLEADING); one item = 0.033 accuracy. Differences of one or two items are noise — read the table as a sanity check, not as a precise optimum.

**Decision (2026-11-12): `fusion.yaml` keeps the defaults (tau 0.6, min_evidence 2, N_months 6).** The best grid point (tau 0.6, min_evidence 1) gets 6 vs 6 of 30 dev items right (macro-F1 +0.0034). min_evidence = 1 would also make R8 unreachable (R3 / R7 would fire on a single source before the single-source rule), i.e. it silently removes the documented single-source safeguard (master §14.2); a gain of at most one item on 30 does not justify that design change. N_months has no effect on dev (no dev claim carries a recency cue, so `old_news` never fires). At the default min_evidence the five tau values span macro-F1 0.1311–0.1542.

Earlier run of the same grid with the TF-IDF + LR classifier (before the DistilBERT checkpoint existed; `train_logs/e2e_tfidf_superseded/fusion_grid.json`): default macro-F1 0.1319, best 0.1848 at tau 0.6, min_evidence 1 — same decision.
